# Lazor 的状态转移约束规划

`lazor/solver.py` 把整个关卡构造成一个布尔与整数约束系统，用 Z3 找到满足
条件的方块配置。得到配置后，`simulate()` 独立计算光路，核对目标、库存、
全部经过点和全部有向线段，确认模型与实际模拟一致。

这是**可行性规划**：求出一个满足规则的配置即可。可以形式上写成
“最小化常数 0”，代码直接调用 `Solver.check()`，没有最短光路或最少方块目标。
应用层不再用 BFS 枚举摆法；Z3 内部仍会进行逻辑推理和搜索，不能把它称为闭式公式。

## 1. 方块决策变量

令可放置方块的原始 `o` 格子集合为 \(C_o\)。每个格子 \(c\) 有一个整数变量：

\[
t_c\in\{0,1,2,3\},\qquad
0=\text{空},\;1=A,\;2=B,\;3=C.
\]

固定 A/B/C 是常量；`x` 是不允许放块、但允许光线通过的空格常量。
固定块不计入待放库存。对每种移动方块类型 \(k\in\{1,2,3\}\)，要求：

\[
\sum_{c\in C_o}[t_c=k]=n_k.
\]

这里 \([Q]\) 在条件 \(Q\) 成立时等于 1，否则为 0。
因此每个格子至多一种类型，每种库存恰好全部用完，且不会改变原始固定块。
所有格子的取值合称配置 \(X\)。

## 2. 光线状态与有限状态空间

光线状态为：

\[
s=(x,y,v_x,v_y),\qquad v_x,v_y\in\{-1,1\}.
\]

位置使用半格坐标，包含棋盘边界。光源与光路状态位于方块面的中点，所以
\(x+y\) 为奇数。方向决定光线准备进入哪一个相邻格子，不能只用位置作为状态。

宽 \(W\)、高 \(H\) 的棋盘有状态集合：

\[
S=\{(x,y,v_x,v_y):0\le x\le2W,\;0\le y\le2H,
\;x+y\equiv1\pmod2,\;v_x,v_y\in\{-1,1\}\}.
\]

\[
N=|S|=4\big((W+1)H+W(H+1)\big)=4(2WH+W+H).
\]

模型显式建立有限个状态与条件边，不需要猜测“最多模拟多少步”。

## 3. 集合值状态转移函数

给定一个配置 \(X\)，定义：

\[
F_X:S\longrightarrow2^S.
\]

它返回所有后继状态的集合。C 会同时产生透射和反射，所以不能只返回一个后继。

令 \(b_X(s)\) 为状态 \(s\) 前方格子的类型。前方格子的整格坐标为：

\[
\operatorname{front}(s)=
\begin{cases}
(x/2-[v_x<0],\;\lfloor y/2\rfloor),&x\text{ 为偶数},\\
(\lfloor x/2\rfloor,\;y/2-[v_y<0]),&x\text{ 为奇数}.
\end{cases}
\]

直行方向为 \(v=(v_x,v_y)\)，反射方向为：

\[
\rho(s)=
\begin{cases}
(-v_x,v_y),&x\text{ 为偶数，即竖直面},\\
(v_x,-v_y),&y\text{ 为偶数，即水平面}.
\end{cases}
\]

对出射方向 \(u=(u_x,u_y)\)，候选后继是
\(s_u=(x+u_x,y+u_y,u_x,u_y)\)。条件如下：

| 分支 | 光学条件 | 后继 |
| --- | --- | --- |
| 直行 | 前方为空或 C | \(s_v\) |
| 反射 | 前方为 A 或 C | \(s_{\rho(s)}\) |
| 遮挡 | 前方为 B | 没有后继 |

两种分支都还要求后继位置在棋盘内，且实际穿过的格子为空或 C。
对于直行，实际穿过的格子就是前方格子；对于反射，是反射方向一侧的格子。
这与模拟器一致，避免光源夹在相邻方块面之间时，反射线段穿过后方的 A/B 内部。
它不额外生成两个紧贴反射面之间的零距离反弹。

把这些判断合在一起，得到每条可能边 \(p\to s\) 的布尔条件
\(g_{p,s}(X)\)。条件为真的后继，恰好组成 \(F_X(p)\)。
边界外不保留线段；到达边界、B 的接触面或光源起点本身，仍可命中目标。

## 4. 为什么只有可达性等式还不够

设 \(L\subseteq S\) 为实际激光起始状态集合。真正的可达状态可定义为最小闭包：

\[
R_0=L,\qquad
R_{i+1}=R_i\cup\bigcup_{p\in R_i}F_X(p),\qquad
R=\bigcup_{i\ge0}R_i.
\]

有限状态空间保证它最终稳定。不过，直接给 Z3 写
“一个状态可达，当且仅当它是源或有可达前驱”，会允许错误的非最小解：
一圈没有光源接入的状态可以互相声称可达，凭空点亮环上的目标。

因此模型必须同时表达**传播闭包**和**能追溯到真实光源的来源证明**。

## 5. 布尔可达性与整数见证层级

每个状态有可达性变量 \(r_s\in\{\text{false},\text{true}\}\)，
以及整数层级 \(d_s\)。

**光源约束：**对 \(s\in L\)，

\[
r_s=\text{true},\qquad d_s=0.
\]

**非光源层级：**对 \(s\notin L\)，

\[
r_s\Rightarrow1\le d_s<N,\qquad
\neg r_s\Rightarrow d_s=-1.
\]

**前向闭包：**对每条条件边 \(p\to s\)，

\[
(r_p\land g_{p,s}(X))\Rightarrow r_s.
\]

只要真实可达的光线能沿该边前进，后继就必须可达。这会保留 C 的所有有效分支，
不能为了绕过某个条件而任意舍弃一条光线。

**来源见证：**对每个非源状态 \(s\notin L\)，

\[
r_s\Rightarrow\bigvee_{p\to s}
\big(r_p\land g_{p,s}(X)\land d_p<d_s\big).
\]

可达状态必须至少有一个已可达、能走到它、且层级更小的前驱。
没有前驱的空析取为 false，因此这种非源状态不能自称可达。

注意：层级只约束**至少一个来源见证**，不是要求所有实际光路边都满足层级递增。
如果给每条物理边都强加严格递增，就会错误禁止真实反射闭环。

## 6. 真实循环允许，无源循环被排除

假设实际光路包含 `source → a → b → c → a`。
可以给 source、a、b、c 分别赋层级 0、1、2、3。
a 的见证前驱选择 source，b 选择 a，c 选择 b；返回边 `c → a` 仍然有效，
但它只需要满足前向闭包，不要求 \(d_c<d_a\)。所以真实闭环完全合法。

如果只有不与任何光源相连的 `a → b → c → a`，三者要全部可达，
就必须沿某组前驱不断严格降低层级。有限非负整数不可能无限下降，且所有
非源可达状态的层级至少为 1；最终必须回溯到层级为 0 的真实源。
这个孤立环没有这样的源，所以不能凭空成为可达状态。

\(d_s<N\) 是有限图来源证明的充分范围，不是限制物理光线运行次数。
任何可达状态都存在至多 \(N-1\) 条边的简单路径，即使实际光线可以继续循环。

## 7. 目标约束与正确性

对每个目标坐标 \(q=(a,b)\)，要求至少一个方向状态可达：

\[
\bigvee_{(a,b,v_x,v_y)\in S}r_{(a,b,v_x,v_y)}.
\]

解析器允许的整数目标如果不是面中点，这个集合为空，约束为 false。
目标不会被静默忽略，也不会制造不属于光路状态空间的命中。

对一个固定配置 \(X\)，以上约束精确刻画从实际光源出发的可达集：

- **没有漏掉真实光路：**源必定可达，沿每条有效边的闭包约束逐步强制后继可达。
- **没有虚构光路：**任何声明可达的非源状态，都可沿严格下降的见证层级追溯
  到真实光源。反向读这条见证链，就是一条有效光路。
- **不会排除合法解：**给真实可达状态设置从任一光源出发的最短边数作为层级，
  不可达状态设置为 -1，就能满足全部见证与闭包约束。

结合库存和目标约束，可满足模型对应一个合法摆法；合法摆法也能构造满足模型。
这个结论以本项目在第 3 节明确的离散光学规则为前提。

## 8. 代码入口、输出与时间限制

| 代码 | 职责 |
| --- | --- |
| `build_planning_model(puzzle)` | 创建格子变量、状态、条件边和全部约束 |
| `PlanningModel.to_smt2()` | 导出可审阅的 SMT-LIB 模型 |
| `solve_constraints(...)` | 控制时间预算，检查可满足性，解码摆法并独立复核 |
| `PlanningResult` | 保存结果状态、模型规模、耗时和成功时的模拟结果 |

```python
from lazor import load_bff
from lazor.solver import solve_constraints

puzzle = load_bff("boards/mad_1.bff")
plan = solve_constraints(
    puzzle, timeout=110, model_path="outputs/mad_1.smt2"
)
if plan.solved:
    print(plan.solution.layout.placements)
else:
    print(plan.status, plan.reason)
```

`solved` 表示模型与独立模拟都通过；`no_solution` 仅在模型被证明 UNSAT 时返回。
`timeout` 和 `unknown` 均不表示无解。
时间预算包括建模、求解和复核；建模与复核在阶段边界检查预算，Z3 使用剩余时间。
因此这不是能在任意 Python 指令中间强制停止的硬实时期限。
编辑器另用独立子进程执行，可由“取消运行”终止。

`state_count`、`transition_count`、`variable_count`、`constraint_count` 表示
模型规模。变量总数含方块决策与可达性/层级辅助变量，约束数为顶层断言数。
它们不是已枚举摆法数量。文本与 SVG 也分别标注规划耗时和最终光线模拟耗时。

命令行可同时输出公式和验证后的图片：

```powershell
python -m lazor boards/mad_1.bff --solve --model outputs/mad_1.smt2 --svg outputs/mad_1_planning.svg
```

已有文件需要加 `--force` 才允许覆盖。完整用法见项目 README。
