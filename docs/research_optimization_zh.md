# 论文检索与第二轮优化实验

本轮从相关论文提出实验假设，再在冻结的上一轮版本上做对照。研究日期为 2026-11-10。修改前代码保存在 `tmp/research_baseline/lazor`，不以最初的慢版本作为这一轮基线。

## 相关问题与论文

1. **David Kempe，2003，On the Complexity of the “Reflections” game**，作者公开的未发表手稿。[原文](https://www.david-kempe.com/publications/reflections.pdf) / [作者说明](https://david-kempe.com/publications.html)。研究在棋盘中放置反射、分光等元件来照亮目标，使用位置与方向构成的有向图。其奇数次命中、炸弹及旋转规则与本项目不同，因此不能把文中的 NP 完全性证明直接当作本项目的证明；可借鉴的是有限方向状态建模与独立路径验证。

2. **Bayless、Bayless、Hoos、Hu，AAAI 2015，SAT Modulo Monotonic Theories**。[正式发表页](https://ojs.aaai.org/index.php/AAAI/article/view/9755) / [预印本](https://arxiv.org/abs/1406.0043)。讨论图可达性等单调理论如何进行传播和冲突学习。本轮据此实验“模拟候选布局，针对未到达目标添加跨越可达集合的边割约束”。本项目的库存约束并不单调；采用的是光学边启用条件上的图推理，不能按方块数量直接套用单调性。

3. **Neng-Fa Zhou，ICLP Technical Communications 2021，Modeling and Solving Graph Synthesis Problems Using SAT-Encoded Reachability Constraints in Picat**。[论文](https://arxiv.org/abs/2109.08293)。展示利用可达性编码求解图合成问题；本轮据此比较不同可达性表达，而不是把其激光相关实例视作本项目的相同规则。

4. **Gomes、Selman、Kautz，AAAI 1998，Boosting Combinatorial Search Through Randomization**。[作者原文](https://www.cs.cornell.edu/gomes/pdf/1998_gomes_aaai_iaai_boosting.pdf)。讨论搜索顺序、随机化与重启对运行时间分布的影响。用于启发多光源处理顺序和重启策略实验；“距离目标近的光源优先”是本项目待实测的启发式，并非论文提供的性能保证。

5. **Lecoutre、Sais、Tabary、Vidal，IJCAI 2007，Nogood Recording from Restarts**。[发表页](https://ijcai.org/proceedings/2007/19)。说明重启时记录失败信息可以避免再次探索相同冲突。本轮评估这一方向，但不会把普通状态去重或改变搜索顺序称为已经实现了冲突学习。

6. **Luby、Sinclair、Zuckerman，1993，Optimal Speedup of Las Vegas Algorithms**。[作者原文](https://www.cs.utexas.edu/~diz/pubs/speedup.pdf)。研究独立随机运行的通用重启序列。上一轮两阶段以及本轮三阶段的确定性重试均不满足同样的随机假设，因此不声称享有该定理的加速界。

7. **Zhou、Wang、Yap，SAT 2023，A Comparison of SAT Encodings for Acyclicity of Directed Graphs**。[正式论文](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.SAT.2023.30)。用于比较秩、位向量及图分解表达的研究背景。本项目只对到达状态的来源见证要求秩严格递增，真实光路仍允许环路，不能把所有光学边误约束为无环。

## 实验原则

- 冻结上一轮代码，并交替运行前后版本，记录相同输入、超时上限和代码哈希。
- 用参考样本筛选方案，选择冻结后才运行新种子的预留评估样本。
- 保留全部超时和错误，不只统计成功案例；采用 PAR-2 时，未完成案例按两倍预算计入。
- 奇偶性无解控制和有解布局分开统计，不能用容易拒绝的无解题证明困难搜索性能。
- 性能改变需要通过小棋盘穷举、回环、相邻分光块及独立模拟复核。

评估依据：[Eggensperger 等，JAIR 2019，Pitfalls and Best Practices in Algorithm Configuration](https://arxiv.org/abs/1705.06058)；[SAT Competition 2024 官方 PAR-2 计分说明](https://github.com/satcompetition/2024/blob/main/README.md)。

## 合入的改动

**SMT 批量构建。** 保留上一轮的完整有界整数秩公式、原生精确库存计数、转移守卫与独立复核；把逐条 Z3Py 构造替换成一次 SMT-LIB 文本解析，减少 Python 与原生库之间的调用。变量名仅由内部整数坐标和编号产生，不插入输入文件文本。这个批量构建是本项目的实现优化，不声称是上述论文提出的算法。初筛 24×24 建模为 0.839→0.265 秒，44×44 为 2.792→0.845 秒；建模快不等于总求解必定完成，后者在该次 5 秒试验中仍超时。

**按工作量限定的三阶段搜索。** 前两阶段分别使用空格优先和 C 优先；每阶段超过 4,096 个决策节点或 65,536 个光线状态时恢复初始状态。第三阶段继续 C 优先，并优先处理靠近未命中目标的待处理光线；它没有阶段工作量截止，只受原始总时间预算限制。因此最终仍是完整搜索，改变顺序不会排除合法答案。所有阶段共享截止时间，节点和光线计数累计；优先级缓存最多 4,096 项。

选择策略时只使用 82 个参考案例，截止时间为 0.3 秒。参考正确结束数为 78→80、超时 4→2；同时存在退步案例 `reference_n42_a07_c10_obstacles`，没有从统计中删去。阈值与策略冻结后，才运行留出集。

**验证。** 179 项回归测试通过。额外进行了 80 个随机固定布局案例的每个合法赋值核对，以及 40 个随机可移动棋盘的穷举对照。独立复核将旧、新完整 SMT 公式做异或，12 组具有不同域/回环/分光/多光源特征的实例全部证明不可满足，即公式等价。搜索测试覆盖两次重试、完整无解、共享截止时间、库存恢复、缓存淘汰与深栈。

批量解析是一次原生调用，不能在解析中间中断；前后均检查预算。外层基准仍有独立进程终止上限，超时不会记作无解。

## 已排除的候选

Python 层的延迟图割原型只为单元格库存建模，完整模拟候选后加入必要的割约束。它在 `custom_test` 的 2 秒内执行了 1,191 次求解检查、添加 1,341 条割约束仍未完成；24×24 障碍题和 44×44 开放题也超时。原型保存在 `tmp/research_lazy.py` 供复现，未作为主求解器发布。这个结果只说明本次 Python/Z3 原型不适合替换现有实现，不能推论原论文的 MonoSAT 实现较慢。

纯静态的目标距离光源排序在参考集上从 78 个正确结束退到 76 个，未采用。删除秩边界、SCC 分组秩、位向量秩、布尔单元格编码在不同尺寸间表现不一致，也未替换原有编码。保留这些负面结果，避免只报告改进的个例。

## 正式对照结果

最终算法冻结后完成 **560 次独立进程试验**：131 个棋盘×两种算法×两个版本=524 次，另对 3 个既有诊断题各做 3 次重复、两种算法和两个版本=36 次。没有错误结论或进程错误。

131 个棋盘均使用每次求解 **1 秒**上限。‘正确结束’包含找到并复核答案，以及证明无解；其中 43 个为容易的奇偶性无解控制。

| 算法 | 上一轮正确结束 | 本轮正确结束 | 超时变化 | PAR-2 变化 |
| --- | ---: | ---: | ---: | ---: |
| 剪枝搜索 | 125/131 | 130/131 | 6→1 | 0.1135→0.0444 秒 |
| SMT | 74/131 | 84/131 | 57→47 | 0.9668→0.8426 秒 |

PAR-2 把未按时完成的案例记为两倍预算，数值越小越好；它不是成功题目的平均实际运行时间。

**独立留出集：** 49 个新布局中，搜索正确结束 47→49，SMT 正确结束 28→32；搜索的两个原超时用例均完成。留出集与参考集共享生成机制，因此这证明的是该合成分布中新布局上的表现，不代表所有真实题库。

**不能声称每题都加速。** 双方都完成的 125 个搜索配对，旧/新耗时比中位数约 0.995、几何平均约 0.973，简单题总体相近并有小幅开销；主要收益来自减少长尾超时。SMT 的 73 个共同完成配对，旧/新比几何平均约 1.122。较短 0.3 秒参考筛选里出现过的退步案例已保留记录。
