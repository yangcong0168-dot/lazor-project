## 实现

1. **跳过无效排序。** 反向引导阶段只有一条待处理光线时，保留目标更新，直接取该光线；剩余库存只有一种有效类型时，直接读该类型，不计算候选优先级。省下来的距离计算可能影响后续缓存的填充与平局顺序，因此依然进行完整行为回归。
2. **减少可达性检查中的重复操作。** 几何转移与静态前驱使用紧凑状态编号索引的列表。每次乐观检查将继承的 `seen` 转为一次只读字节位图；局部访问用本次检查的编号标记，避免每访问一个状态就构造、更新宽整数。保持原有 LIFO 遍历、目标早停、每 32 个节点检查一次的频率，不缓存跨布局的可达结论，也不改变剪枝规则。
3. **隐式强制格。** 当剩余库存的有效类型只有一种时，所有未决定格都只能取这个值。沿光路直接读取它，不修改格子、库存或撤销轨迹；最后统一补齐库存。该段不会产生新分支，回溯到旧决策后重新计算隐式类型。

`forced_assignments` 继续表示实际强制写入；`assignment_writes` 记录所有具体赋值写入，不含回滚；`implicit_cell_reads` 记录隐式类型读取次数，同一个格子可以重复计数。三者不是可互换的计数，不能把隐式读取当成不存在的工作。独立模拟仍复核完整库存和所有目标。

## 选择依据与验证口径

本轮重新测量基线：每题 1 秒、串行隔离持久工作进程，5,997 题全部及时正确完成，零错误和超时，累计算法耗时 118.773 秒。环境下的运行时间会有波动，因此本轮收益以这次新测基线为准，不混用上轮的 134.972 秒。

方案 2 的独立试验覆盖 250 个随机小棋盘及两个补充案例，5 种表示共 1,260 次比较；结果、具体布局和原有工作计数全部一致，随机题另与完整枚举核对。38 题分层筛选中，基线合计 2.101 秒，紧凑索引＋访问编号标记为 1.375 秒；所有题均正确，搜索路径和计数相同。这是表示方法的筛选结果，不冒充三项组合的全量收益。

组合后另做 38 题轮换顺序的消融测试，所有候选均 32 个有解、6 个无解，零错误或超时：

| 候选 | 累计算法耗时 |
| --- | ---: |
| 冻结基线 | 2.069 秒 |
| 只实现 1＋3 | 1.933 秒 |
| 只实现 2 | 1.419 秒 |
| 实现全部三项 | 1.264 秒 |

正式复测使用原 5,997 题、原 164 个新种子题的回归，以及代码冻结后另行生成的 164 个新种子题。新集排除原矩阵、上一轮 131 题面板和已有 164 题的所有输入哈希；不根据新集结果调整策略。两类有解题与容易的奇偶性无解控制分开统计。

所有比较保留超时、错误和变慢的案例，分别报告总算法耗时、节点、光线状态、检查次数和实际写入。访问标记优化降低单次访问成本，不等价于减少光线访问次数。新增种子仍来自相同生成器，不能据此声称跨外部真实题库的普遍加速。
