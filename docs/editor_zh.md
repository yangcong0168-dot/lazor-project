# Lazor 图形测试编辑器

编辑器是一个独立的本地桌面窗口，用 Python 标准库 Tkinter 实现。
界面与模拟无需网站或账户。自动求解使用本地 Z3 约束求解器，
首次安装依赖后可离线运行。它生成课程要求的 **`.bff` 文件**；
这里不另外定义 `.bif` 格式。

## 启动

在项目根目录双击 **`Launch Editor.cmd`**。
启动器会寻找已有的 Python 3.10 或更新版本，并检查能否导入 Tkinter。
建议使用项目已经验证过的 Python 3.12 运行环境，并通过 `python --version`
确认命令指向的解释器。

也可以在项目根目录运行：

```powershell
python -m lazor.editor
python -m lazor.editor boards/mad_1.bff
```

自动规划还需要 `requirements.txt` 中的 `z3-solver`。使用运行编辑器的同一个
Python 安装依赖：

```powershell
python -m pip install -r requirements.txt
```

也可以按根目录 README 的说明，将依赖安装到项目自己的 `.deps` 目录。

启动器不安装软件、不修改系统设置。其他电脑需要自己的 Python 3.10+，
并在安装 Python 时包含 Tcl/Tk 组件。若启动后没有窗口，可在终端使用上述
命令查看错误信息。

## 创建一个光路测试

1. 新建棋盘，设置宽度和高度。尺寸以完整方块为单位。
2. 在左侧选择工具，再点击棋盘。
3. 选择激光工具及右上、右下、左上或左下方向，点击希望的发射位置。
4. 选择目标工具，点击需要光经过的位置。
5. 运行模拟，查看光路和命中结果。
6. 保存为 `.bff`，以后可以重新打开，或交给命令行批量测试。

可用工具：

| 工具 | 保存到文件的内容 |
| --- | --- |
| 空格 `o` | 空的、允许放置可移动方块的位置 |
| 禁放 `x` | 不允许放方块的位置；光仍可通过 |
| 反射块 `A` | 棋盘中的固定反射块 |
| 遮挡块 `B` | 棋盘中的固定遮挡块 |
| 折射块 `C` | 棋盘中的固定折射块 |
| 激光 `L` | 光源位置与方向，可以设置多条 |
| 目标 `P` | 必须经过的坐标点 |
| 橡皮 | 删除点上的对象或清除格子 |

鼠标右键也可擦除。撤销和重做可以恢复误操作。
运行结果只是叠加到棋盘上；修改关卡后，旧光路会清除，避免把旧结果当成新结果。

## 固定方块和可移动库存

**用鼠标画到棋盘里的 A/B/C 都是固定方块。**
如果你希望测试“光遇到这个摆法会如何反射”，直接在棋盘上摆方块即可。

如果你希望约束规划自动寻找摆法，则在库存输入框中填写可移动 A/B/C 的数量。
这些库存没有预先指定位置，求解器把它们的位置作为决策变量，
用状态转移、库存和目标可达约束确定它们应放在哪些 `o` 格子中。
库存总数不能超过可放置的空格数量。

例如，一个固定 C 加两个待求解的 A，在文件里表示为：

```text
GRID START
o o o
o C o
o o o
GRID STOP
A 2
B 0
C 0
```

库存中的 `C 0` 不会删除棋盘里的固定 C，它们是两种不同的数据。

## 坐标和点击位置

方块按整个格子摆放；激光和目标使用半格坐标。
一个方块的宽、高各相当于 2 个坐标单位。左上角是 `(0, 0)`，
x 向右增大，y 向下增大。

激光需要放在格子边的中点，也就是 x、y 一个为奇数、另一个为偶数的位置。
编辑器会帮助吸附到可用位置。四种方向分别对应：

| 方向 | `(vx, vy)` |
| --- | --- |
| 右下 | `(1, 1)` |
| 右上 | `(1, -1)` |
| 左下 | `(-1, 1)` |
| 左上 | `(-1, -1)` |

发射点可以位于棋盘边界。若朝棋盘外发射，光只经过起点后就离开。
目标工具同样吸附到边中点。导入文件中其他整数坐标的目标仍会显示，
可以用右键或橡皮擦删除。编辑器支持 1×1 到 16×16 的棋盘。

项目附带 `boards/loop_demo.bff`：四个反射块围出闭环。打开后运行模拟，
应看到四个目标全部命中，并正常结束，不会陷入无限循环。

## 模拟、约束规划和取消

**模拟**检查你当前画好的固定摆法。尚未放置的库存不会自动加入光路。
如果目标全命中但还有库存，程序会区分这种状态和完整解。

**约束规划求解**在原固定块不变的情况下自动安排库存。
找到的可移动块会作为结果叠加显示，不会直接改写你的原始题目。
因此保存关卡时，仍保留原来的 `o` 格子和库存。

计算在后台进程中运行，窗口可以继续响应取消操作。
取消只结束本次测试，不改变保存的关卡。
界面默认规划时间预算为 15 秒，可设置为不超过 110 秒的正数。
计算期间暂时禁用编辑，避免结果与草稿不一致。
约束不可满足表示模型下无解；超时或求解器返回 unknown 都不能证明关卡无解。
结果显示模型状态数、约束数和总耗时，不再显示枚举候选数。

## 保存和导出结果

- **保存关卡**：保存原始设计为 `.bff`，包括固定块、库存、激光和目标。
- **导出结果**：保存本次计算的 SVG 光路图、文本报告和摆法快照 `.bff`。

结果快照会把已摆好的块写成固定块，用于复现光路；它不能替代用于重新求解的
原始设计。建议原始题目放在 `boards/`，结果放在 `outputs/`。

右侧 `.bff` 预览可查看当前关卡将保存的内容。未完成的草稿也能预览，
但保存或运行前需要通过校验：至少一个激光、至少一个目标、合法坐标与方向，
以及不超过可用空格的库存。遇到问题时会显示错误，不会导出一个无法读取的关卡。

常用快捷键：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+S` | 保存关卡 |
| `Ctrl+O` | 打开关卡 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |

新建、打开或关闭前，若有未保存修改，编辑器会询问如何处理。

保存后也可直接运行现有命令：

```powershell
python -m lazor boards/my_test.bff --simulate
python -m lazor boards/my_test.bff --solve --svg outputs/my_test.svg
python -m lazor.benchmark boards --output outputs/benchmark.json
```

命令行不会覆盖已有输出文件；确认需要覆盖时添加 `--force`。

模型的数学定义和循环处理见[状态转移规划说明](planning_model_zh.md)。
更新代码后，已经打开的编辑器仍使用旧代码；先保存草稿，再关闭并重新启动。
